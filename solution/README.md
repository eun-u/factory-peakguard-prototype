# 과제 ⑤ 제출용 구현 공간

이 폴더는 최종 전력예측·피크위험 분석 코드의 자리다. 현재 확정된 제출 모델은 없으며, prototype/의 화면과 verification/의 사전 타당성 코드를 그대로 최종 구현으로 간주하지 않는다.

개발할 때 학습·검증·시험의 시간 경계, 입력 변수의 예측 시점 가용성, 전처리와 결측·시각 복원 기록, 모델 비교, 추론 결과 생성을 한 명령으로 재현할 수 있도록 구성한다. 제출 ZIP은 이 구현과 필요한 학습용 데이터·환경 파일·README·테스트 예측결과를 기준으로 만든다.

기존 ⑤ 검증의 경계와 한계는 verification/results/report.md 및 05b_report.md에 있다. 전력 단위, 15분 열의 경계, 설비별 가동·제품 전환 정보가 확인되지 않은 상태에서 실제 요금 절감이나 일정 변경의 효과를 주장하지 않는다.
