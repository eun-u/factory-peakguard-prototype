# 과제 ⑤ 확인 문의 문안

발송 상태: 미발송. 발신자 계정과 수신처가 확정되지 않았으며 발송 성공을 주장하지 않는다.

안녕하세요. 과제 ⑤ 분석 및 제출 형식과 관련해 다음 사항을 확인 부탁드립니다.

1. 평가표의 정량지표는 어떤 지표이며 별도 테스트 데이터·예측 제출 양식이 있습니까?
2. 지정 예측 시간구간은 15분·1시간·익일 중 어떤 구간입니까?
3. 전력 15/30/45/60분 열의 단위는 kW 또는 kWh 중 무엇이며 각 열이 구간 종료 시각을 뜻합니까?
4. 생산량은 시간 종료 후 확정된 실적입니까? 계획 생산량 자료는 별도로 있습니까?
5. 만족도 설문 링크와 완료 화면의 보고서 첨부 위치를 안내 부탁드립니다.

감사합니다.
