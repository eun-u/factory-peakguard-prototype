## 연구 기본 정의

| 항목 | 정의 |
| --- | --- |
| Background | 제조 전력의 시간·생산 패턴에 따른 변동과 피크 위험을 다룬다. 평균 오차, 고부하 오차, 운영 경보의 유용성을 구분하여 분석한다. |
| Objective | 주 과제는 한 시간 뒤에 끝나는 15분 구간의 전력값과 피크 위험 예측이다. 피크 MAE 개선을 주목표로 두고 오경보·준비시간·실패 조건·활용 가능성을 검증한다. |
| Method | 시간·완료 생산 맥락을 이용한 점예측, 분위수 예측과 보정, 확률 경보, 조건별 오류 분석을 연결한다. 점예측·확률 경보 결합은 후속 가설이며 아직 채택된 정책이 아니다. 최종 예측기는 비교 실험으로 선정한다. |
| Dataset | 대회 자원 최적화 AI 데이터셋. 6,168시간 행을 24,672개의 15분 관측으로 구성. 2021-01-01 00:15~2021-09-15 00:00. 복원 구간 및 의존 특징·목표 제외, 단위·시간 경계 미확인, 실제 미래 생산·기상은 예측에서 제외. |
| Baselines | 현재값 유지, 전일·전주 동일 시각, CBL 준용, 기본 LightGBM. 현행 결합 모델은 개선 전 기준점이고 Chronos는 후속 후보. 경보는 점예측 단독·확률 단독·기존 확률/q95 정책과 비교한다. |
| Evaluation | h4 피크 MAE가 주 지표. 전체 오차·사건 F1/재현율·FP·준비시간·커버리지 병기. 시간순 학습/보정/평가 분리, 동일 행 비교, 날짜 블록 CI, 제거 실험, 지연·기간 변화 분석. 기존 평가 이력 보존. |
| Result | 현재 결과는 paper/generated/results.md에서 기존 근거로 생성한다. 새 모델 개선·경보 결합·현장 절감 효과를 완료로 표시하지 않는다. |
| Conclusion | 개발 비교에서 h4 점예측 개선 증거가 있으나 경보 품질과 기간별 안정성은 별도 검증이 필요하다. 최종 결론은 방법의 유효 조건·예측거리·한계로 제한한다. |
| Threats | 개발 결과의 반복 열람과 선택 편향, 과거 마지막 15% 테스트 열람, 제한된 공장·기간, 미확인 단위·구간 경계, 통계적 피크와 계약 한도의 차이, 사후 시뮬레이션의 인과 해석 한계. |
| Pros | 제조 데이터와 구체적인 문제, 강한 기준선, 시계열 검증, 불확실성·경보·실패 분석을 연결할 기반이 있다. |
| Cons | 설비·작업 제약·실제 조치 결과가 부족하며 기간·거리별 성능이 균일하지 않다. 복수 방법을 결합하므로 구성요소의 추가 가치를 따로 입증해야 한다. |
| Contribution | 검증할 기여는 피크 예측 성능과 유효 범위, 불확실성·준비시간을 고려한 경보의 추가 효과, 제조 맥락·지연·기간 변화에 따른 실패 조건이다. 독창성은 선행연구와 대조하며 LLM/KG를 필수로 전제하지 않는다. |

## 알려진 한계

- 개발 결과이며 최종 현장 성능이나 실제 절감 효과가 아니다.
- 마지막 15% 테스트를 과거에 1회 열람했으며 재봉인으로 미열람성이 복원되지 않는다.
- 전력 단위·15분 경계·설비별 제약·실제 교대가 미확인이다.
- h4는 원점+60분에 끝나는 단일 구간이며 다음 한 시간의 최대나 전체 미래 궤적이 아니다.
- h4 위험 모델은 기존 conformal:b 필드로 지정되어 P4 요약과 교차 확인한다. 과거 ranking_evidence는 최신 모델 지표로 재사용하지 않는다.
- P6 walk-forward의 공통 τ는 원 JSON 177과 과거 요약 176이 불일치한다. 원인 확인 전 요약 수치를 전용하지 않는다.
- 신규 실험 계획은 planned 상태다. 기존 결과를 본 후의 가설이며 실행 전 후보·예산·판정 기준의 별도 고정이 필요하다.
