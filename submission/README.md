# 제출물 작업 공간

공문 원본(docs/official/) 기준 제출 기한은 **2026-10-08 23:59**다. 아래는 제출을 위한 폴더 배치이며, 현재 제출물이 완성됐다는 뜻이 아니다. 공식 포털의 이후 변경 공지는 제출 전에 확인한다.

| 폴더 | 준비할 파일 |
| :-- | :-- |
| report/ | 첨부 양식에 맞춘 결과 보고서 PDF. 설문 완료 화면을 보고서에 포함 |
| source/ | 소스코드 ZIP. 코드, requirements.txt 또는 environment.yml, 학습용 데이터, README, 테스트 데이터 예측결과 파일 포함 |
| presentation/ | 같은 발표자료의 PDF와 PPT 파일 |
| survey/ | 설문 완료 화면 원본 캡처. 보고서에 삽입한 출처 보존용 |

## 제출 전 확인

- 모든 제출물에서 기업·학교명, 로고 등 소속을 식별할 수 있는 정보를 제거한다. 공문에는 성명과 팀명은 허용된다고 적혀 있다.
- ZIP을 새 환경에서 풀어 전처리부터 학습·추론·결과 파일 생성까지 다시 실행하고, README의 명령과 데이터 경로가 일치하는지 확인한다.
- 제출용 소스 묶음은 선택 과제 ⑤의 확정 구현과 필요한 자료만으로 구성한다. 내부 의사결정 DOCX, ②·③ 원본, 과거 검증 작업물을 자동으로 포함하지 않는다.
- 결과 보고서의 예측 성능은 선택한 테스트 기간과 재현 가능한 코드에 연결한다. verification/results/의 사전 타당성 보고서를 최종 제출 성능으로 그대로 전용하지 않는다.
- 원본 데이터의 배포·제출 범위는 대회 안내에 맞춰 확인한다. 이 저장소의 data/raw/는 Git에 포함하지 않는다.

공문이 요구하는 제출은 KAMP 포털 온라인 제출이며, 이 폴더는 로컬 준비 공간이다.
