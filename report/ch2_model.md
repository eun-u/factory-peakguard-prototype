# 제2장 AI 예측모델 개발 및 성능평가

> **이 장의 주장.**
> **C2.** 1시간 후 15분 전력 예측에서 LightGBM은 가장 강한 기준선(직전 15분 persistence)보다 피크 위치 오차와 오경보를 줄인다.
> **C3.** 이 개선은 1시간 예측에 한정된다. 익일 일간 최대 예측에서는 상대오차 기준으로 기준선을 이기지 못한다.

## 2.1 예측 과제

**주 과제(A1).** 원점 t(15분 단위)에서 t까지 관측된 정보 Xₜ로 1시간 뒤 15분 구간 전력 yₜ₊₄를 예측한다.

  ŷₜ₊₄ = f(Xₜ),  Xₜ = {전력 y_s (s ≤ t), 완료된 시간의 생산량, 목표 시각의 달력}

**보조 과제(A1).** 날짜 D의 23:45에 다음 달력날 D+1의 최대 15분 전력 max y를 예측한다.

출제문의 "지정된 시간구간"이 확정되지 않았으므로, 주 과제의 해석 범위를 예측거리 15분·1시간·4시간·24시간 곡선으로 보완한다(2.5.6절).

## 2.2 평가 지표

피크 경계 τ = 학습 구간 목표값의 95% 분위(176.00). 피크 위치 집합 P = {i : yᵢ > τ}.

| 지표 | 정의 | 순위 |
| :-- | :-- | :-- |
| 피크 위치 MAE | (1/\|P\|) Σ_{i∈P} \|yᵢ − ŷᵢ\| | **주 1** |
| 피크 에피소드 F1 | 실제 에피소드(연속 초과 위치 묶음)와 경보 에피소드(연속 경보 묶음)를 시간 겹침으로 **최대 1:1 매칭**한 TP·FP·FN의 F1. 긴 경보 하나가 여러 실제 에피소드를 맞힌 것으로 세지 않는다 | **주 2** |
| 오경보 수 | 비피크 위치에서 경보가 난 15분 위치 수 | **주 3** |
| 커버리지 오차 | \|P(y ≤ q̂_α) − α\|, α = 0.9, 0.95 | **주 4** |
| 전체 MAE·RMSE·MAPE | MAPE는 실제값 0 제외 | 보조 |
| 피크 에피소드·발생일 MAE | 에피소드·날짜마다 피크 위치 절대오차 평균을 낸 뒤 단위별 동일 가중 | 보조 |
| 위치 F1, 날짜 F1 | 날짜 F1은 하루 한 번만 경보해도 맞힌 것으로 보므로 느슨한 지표 | 보조 |
| 평균 pinball 손실 | 분위수 0.1·0.5·0.9·0.95 평균 | 보조 |
| PR-AUC, Brier | 피크 초과 확률의 순위·보정 품질 | 보조 |

경보는 점수 ≥ c일 때 울리며, c는 모델마다 **검증 구간 위치 F1을 최대로 하는 값**으로 시험 전에 고정한다. 모든 비교는 같은 분할, 같은 경계 τ, 같은 임계값 결정 규칙에서 수행한다.

### 2.5.3 피크 사건 탐지

*표 2-6. 테스트 구간 피크 사건 탐지 (실제: 위치 372, 에피소드 147, 피크 발생일 26 / 38일)* 〔V〕

| 모델 | 검증 고정 임계값 | 위치 F1 | **에피소드 F1** | 날짜 F1 | 위치 TP/**FP**/FN | 에피소드 TP/FP/FN |
| :-- | --: | --: | --: | --: | :-- | :-- |
| M1 계절 나이브 | 165.0 | 0.426 [0.335, 0.519] | 0.534 [0.425, 0.631] | 0.875 [0.757, 0.960] | 200/368/172 | 71/48/76 |

persistence는 검증 F1을 최대로 하는 임계값이 142로 낮게 잡혀, 실제 피크 위치를 289개 맞히는 대신 오경보를 774건 냈다. "지금 높으면 1시간 뒤에도 높다"는 규칙은 피크 직전의 상승 구간 전체에 경보를 내기 때문이다. LightGBM은 비슷한 수의 피크 위치(295개)를 맞히면서 오경보를 305건으로 줄였다(−60.6%). 날짜 F1은 세 모델 모두 높아 모델을 구분하지 못한다. 하루 한 번만 경보해도 맞힌 것으로 보기 때문이며, 이 지표를 선정 근거로 쓰지 않는다.

에피소드 매칭은 보수적이다. LightGBM 경보가 시간상 겹친 실제 에피소드는 147개 중 126개(85.7%)였지만, 1:1 매칭에서는 90개만 TP로 센다 〔D〕. 주간의 짧고 끊긴 실제 에피소드 여러 개를 하나의 긴 경보가 덮는 경우가 많기 때문이다.

LightGBM은 RMSE를 크게 줄였지만(큰 오차를 줄임) MAPE는 나이브보다 나빴다. 일간 최대가 낮은 날(휴무일 등)에 상대오차가 커졌기 때문으로 보이나, 36일·피크일 5일로는 원인을 가릴 수 없다. 모든 구간이 넓게 겹친다. **익일 최대 예측에서 LightGBM이 낫다는 주장은 하지 않는다.**

## 2.7 최종 모델 선정 근거

사전에 정한 주 지표 순서대로 판단한다.

1. **피크 위치 MAE.** LightGBM 17.77 [13.88, 22.28] < persistence 27.73 [25.45, 30.53] < 계절 나이브 59.26. 기준선 대비 개선률 0.359 [0.196, 0.501]로 구간 하한이 0보다 크다. → LightGBM.
2. **피크 에피소드 F1.** LightGBM 0.636 [0.585, 0.678] > 계절 나이브 0.534 > persistence 0.451 [0.396, 0.511]. LightGBM과 persistence의 구간이 겹치지 않는다. → LightGBM.
3. **오경보 수.** LightGBM 305 < 계절 나이브 368 < persistence 774. → LightGBM.
4. **커버리지 오차.** 분위수를 내는 모델은 LightGBM뿐이므로 비교가 아닌 품질 점검이다. 0.95 분위수 오차 0.039로 과소 커버리지 → 운영에서 "주의" 단계로만 쓰고, 보정은 개발 폴드에서 검증한다.

**최종 구성.**

| 역할 | 구성 | 선정 근거 |
| :-- | :-- | :-- |
| 1시간 후 점예측 | M3 LightGBM 회귀 | 주 지표 1~3 |
| 조치 경보 | M3 점예측 ≥ 165.2 (검증 F1 최대 임계값) | 주 지표 1로 고른 모델의 출력을 그대로 사용. 확률 방식 A·B와의 F1 차이는 구간 안 |

경보 점수를 세 방식 중 테스트 F1이 가장 높은 것(방식 A, 0.623)으로 고르지 않았다. 테스트 결과를 보고 고르면 테스트 재사용이 되므로, "주 지표 1로 고른 모델의 점예측을 쓴다"는 규칙을 따랐다.

- **C2: 지지.** 최강 기준선 대비 피크 위치 MAE 35.9% [19.6, 50.1] 감소, 에피소드 F1 0.451 → 0.636, 오경보 774 → 305. 사전 기준 K5-d 비해당.
