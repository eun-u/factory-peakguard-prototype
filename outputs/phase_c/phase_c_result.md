# Phase C Model Selection 결과

Development-only. 상태: selected. M*: **B5** (Weekly-deviation Kalman). Strongest baseline: **B1** (Weekly Seasonal). h*는 선택하지 않았다.

## 핵심 판정 해설

B5 선택은 독보적인 정확도 우위가 아니라 사전등록된 complexity tie-break의 결과다. 적격 후보 중 최소 AUC-MAE는 M1이고, B5−M1 차이는 0.2793, 95% CI [-1.9564, 2.4270]로 0을 포함한다. 동률 집합은 ['M1', 'M1-W', 'B5']이다. B5의 AUC-MAE는 strongest baseline B1보다 32.09% 낮지만, 모든 fold에서 개선된 것은 아니다(2/3 fold 개선).

TCN(M2)은 MAIN10의 전체 MAE가 가장 낮지만 peak safeguard에서 탈락했다. M2−B1의 AUC-PeakMAE 차이는 11.6323, 95% CI [2.5967, 21.2126]다. Residual(C1)의 기각 사유는 `no_clear_auc_mae_gain_vs_M1;fewer_than_two_positive_folds;D2_worse_than_M1`이며, 기대와 달라도 구제 튜닝을 하지 않았다. R1은 전체 MAE가 낮아도 reference-only이므로 선택 대상이 아니다.

D2에서 B5의 AUC-MAE는 15.1160, M1는 15.0659, B1는 24.1795다. B5의 D1/D2 순위는 각각 4/3위다. baseline 대비 개선 방향은 유지되지만 유일한 MAE 1위라는 뜻은 아니다.

## 실험 목적과 고정 설계

고정된 G0+G1+G2 정보 아래 1~4시간 전체를 담당할 하나의 대표 예측 구조를 비교했다. 13개 horizon은 60~240분, 15분 간격이며 개별 Direct 모델이다. 3개 시간순 development fold의 fit/stop/cal/score 역할과 horizon purge를 유지했다. 원본 Phase B 임시 코드에서 15개 core 특징 계산식을 확인했으며, 특히 r4_std는 ddof=1이다. feature search, horizon별 configuration 탐색, ensemble, 신규 exogenous 입력을 수행하지 않았다.

원자료 SHA-256, 입력 명세, 코드, 사전등록 문서는 logs/preregistration_lock.json에 결속돼 있다. full raw 파일의 바이트 해시/복사는 무결성 확인에만 사용하고 수치 파싱은 2021-08-09 09:45 미만의 봉인 로더로 제한했다. 모든 통계적 peak는 y>Q95(y_fit)이고 계약전력 초과를 의미하지 않는다.
