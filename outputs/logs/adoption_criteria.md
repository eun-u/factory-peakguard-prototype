# 사전 채택 기준

고정일 2026-09-24. 개발 실행 전 생성. 결과를 본 뒤 기준을 바꾸지 않는다.
평가 범위는 동결 테스트 이전 개발 구간이다. 날짜 블록 1000회, 동일 날짜 재표집을 쓴다.

| 항목 | 채택 조건 |
| --- | --- |
| 공휴일·징검다리 특징 | 휴일·전후일 MAE 개선 95% CI 하한 > 0, 전체 MAE 악화 없음 |
| 피크 가중 | 피크 위치 MAE 개선, 위치 오경보 증가 20% 이내 |
| Mondrian 보정 B | 상위 예측 구간 q95 커버리지 오차 < 전역 A, 전체 pinball 악화 ≤ 5% |
| 기대 초과량 | 실제 초과 에피소드 순위상관의 날짜 블록 95% CI 하한 > 0 |
| 확률 분류 B | A 대비 에피소드 F1 또는 Brier 개선 CI 하한 > 0; 이번 실행 비활성 |
| 파운데이션 모델 | 비교 전용; 이번 실행 비활성 |

대표 기준선은 계열별 개발 전체 MAE 최소. 최종 선정은 피크 MAE CI, 에피소드 F1 CI, 위치 FP, 상위 q95 커버리지 오차, 단순성 순이다.
분위수 보정 표본으로 커버리지 개선을 평가하지 않는다. 각 폴드의 학습 뒤 보정 구간과 평가 구간을 분리하고 예측거리 간격을 둔다.
비용 단가·계약종별 미확인 시 화폐 성과 또는 공식 비용 비중으로 해석하지 않는다.
