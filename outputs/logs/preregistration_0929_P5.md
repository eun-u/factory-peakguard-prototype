# Phase 5 사전 고정 부록 — 사전학습 모델(Chronos-2) 승격 검토

작성 2026-09-29 00:05 KST. P5 후보를 채점하기 전에 작성했고, 작성 후 수정하지 않는다.

## 0. 공개 사항 (사후 승격)

- P4 사전 고정(preregistration_0928_P4.md)에서 Chronos-2는 **참고 전용**이었다. 개발 CV 결과(1시간 피크 MAE 10.80, 전체 MAE 5.22)를 **본 뒤에** 사람 결정으로 후보로 승격한다. 이 순서를 보고서 2장과 발표에 그대로 밝힌다.
- 승격 근거: Chronos-2는 다수 후보 중 사후 선택된 모델이 아니라 단일 사전 등록 비교군이고, 개발 CV 격차가 크다. 최종 판단은 동결 후 테스트 1회로 확인한다.
- P4 결과와 채택 판단은 바꾸지 않는다. P4 표는 그대로 보고한다.
- CLAUDE.md 4.4의 "사전학습 모델은 참고 전용" 문구는 이 부록에 따라 "학습 없이 쓰는 사전학습 모델은 사전 규칙 통과 시 후보 허용, 딥러닝 모델 학습은 계속 금지"로 바꾼다(사람 승인 2026-09-29).

## 1. 입력과 incumbent

- 입력·분할·τ·cal/score 구간은 P4와 동일. Chronos-2 예측은 P4에서 만든 캐시(amazon/chronos-2, revision 29ec3766d36d6f73f0696f85560a422f50e8498c, 원점 이하 봉인 전력 최근 2048개, 중앙값)를 그대로 쓴다. 새 Chronos 설정(문맥 길이, 공변량, 분위수)은 시도하지 않는다.
- incumbent는 P4 사전 규칙의 선정 결과: h1 `p4_mstl_daily`, h4 `p4_blend3`, h16 `lgbm_residual_cbl`, h96 `c3_holiday_hybrid`.

## 2. 후보 (거리마다 2개)

- **P5-A `p5_chronos2`**: Chronos-2 중앙값 단독. P4의 `p4_chronos2_ref`와 같은 예측값이며 이름만 바꾼다.
- **P5-B `p5_blend4`**: {LGBM(`lgbm_no_holiday_weight_2` 재학습), CBL 대표, P4-1 DSHW, Chronos-2} 가중합. 가중치는 합 1·음수 없음·0.1 격자(286점), cal 구간 전체 MAE 최소(동률은 격자 순서 첫 항). P4-4와 같은 규칙에 구성요소 하나만 추가한다.

## 3. 채택 규칙

P4 4절과 같다. 단 Holm 가족은 P5 후보 8개(2후보×4거리)다. 여러 후보가 통과하면 피크 MAE 개선이 큰 쪽, 동률이면 P5-A.

1. 피크 위치 MAE 개선(incumbent − 후보) > 0, 중심화 단방향 날짜 블록 p의 Holm 조정 < 0.05.
2. 에피소드 F1 ≥ incumbent − 0.02, 위치 오경보 ≤ incumbent × 1.20.
3. 마지막 폴드 피크 MAE ≤ incumbent × 1.10, 모든 폴드 ≤ 1.50.

위험 출력(분위수·경보 확률)은 바꾸지 않는다. P5 후보는 점예측만 대체한다.

## 4. 재현성 조건

채택하려면 추가로 다음을 만족해야 한다.
- 모델 가중치를 revision 고정으로 불러오고, 인터넷 없이 실행할 수 있도록 로컬 경로 로딩을 지원한다(제출 ZIP 동봉 또는 설치 안내).
- CPU 실행 시간을 측정해 README에 적는다.
- 3장 영향요인 분석(permutation importance, PDP)은 LightGBM 구성요소로 수행하며, 최종 점예측 모델과 분석 모델이 다르다는 점을 명시한다.
