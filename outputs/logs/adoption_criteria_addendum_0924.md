## 작업 2: 대칭 보조 지표

- peak_mae_union: 실제 y > tau 또는 점예측 pred > tau인 위치의 MAE.
- peak_bias: 실제 피크에서 평균(pred - y).
- overpredict_rate: 실제 비피크에서 pred > tau의 비율.
- 공집합 조건부 평균은 NaN, 분모와 표본 수를 기록한다. NaN을 0으로 바꾸지 않는다.
- 모든 거리·후보에 위 지표, 기존 peak_mae, 위치 오경보, 에피소드 F1 및
  날짜 블록 1000회 95% 백분위 CI를 기록한다. seed는 기존 설정의 42이다.
- 기존 위치 오경보와 에피소드 F1은 기존 보정 경보(alert)를 따른다.
  새 union/overpredict는 tau 초과 점예측을 따르므로 두 정의를 구별한다.
- lgbm_quantile_* q50은 reference_only=True, selection_used=False로 명시한다.
- 날짜 재표집은 원래 시간상의 에피소드 연결을 보존하며 재표집한 날짜 사이를
  인위적으로 연결하지 않는다. 기존 bootstrap 구현을 우선 재사용한다.

## 작업 4: 부하 이동 v2

모든 결과는 **사후 관측 생산량 기반 사후 가정 시나리오**이다.
기존 h4 운영 경보 조건을 그대로 사용한다. 비율 10/20/30%, 준비 15/30/60분.

- D 지연 이동: 도착 후보는 원점+준비시간 이후의 1시간 창이다.
  창 시작 >= 원점+준비시간, 창 끝 <= 원점+24시간으로 해석한다.
  15분 격자에서 검사하고, 출발 창과 겹치는 창은 제외한다.
  도착 요금 가중치가 출발보다 낮고 이동 후 네 구간 전력이 모두 해당 폴드
  tau 이하인 후보 중 가장 이른 창을 택한다.
- C 감축: 출발 창의 부하를 지정 비율만큼 줄이고 이동하지 않는다.
  달성 가능한 피크 감소 상한의 참고용이다.
- 출발도 원점+준비시간 이후여야 한다. 같은 출발 시간에 여러 경보가 있으면
  최초 유효 경보로 한 번만 조치한다. 순차 시뮬레이션으로 기존 이동을 누적한다.
- 관측 생산량과 학습 자료에 적합한 에너지 기준선의 생산량 계수로 D 전력 이동을
  근사한다. 음수 계수는 이동 근거가 없으므로 적용하지 않고 사유를 기록한다.
- 출발·도착의 관측은 같은 폴드 OOF 평가 기간 안에 있어야 한다. 결측·복원 구간,
  개발 경계 밖은 후보에서 제외하고 이유를 집계한다. 과거/테스트로 이동하지 않는다.
- 확인된 단가가 없으므로 기존 요금 시간대의 순서형 가중치를 사용하며 실제 비용으로
  부르지 않는다. 경보 중 조치 가능 비율, 월별 최대 수요 변화, 요금대 가중 사용량
  변화, 이동으로 새로 생긴 피크 위치 수를 분리 보고한다. 기존 결과는 보존하고
  새 결과 이름에 _v2를 붙인다.

## 작업 5: 피크 유형 v2

에피소드 최대 시각에서 excess=y-slot_typical,
rise=baseline(t)-baseline_typical, share=clip(rise/excess,0,1).
slot_typical은 해당 폴드 학습 구간 같은 요일유형(평일/휴일)·15분 위치 중앙값,
baseline_typical은 같은 학습 셀의 Ridge 예측 중앙값이다.
셀 부재 시 같은 15분 위치의 학습 중앙값, 그것도 없으면 학습 전체 중앙값으로
대체하고 대체 여부를 표시한다. excess<=0 또는 비유한 값이면 분류 불가로 남긴다.

- share>=0.5: 생산 기인형(인과 주장이 아닌 설명 비율 명칭).
- 0.2<=share<0.5: 혼합형. share<0.2: 잔차형.
- Ridge는 각 폴드 학습 자료에만 적합한다. 폴드 외 R², 생산량 계수 부호 및
  학습 날짜 블록 1000회 재적합 계수 95% CI를 보고한다.
- 주 신뢰성 문턱은 통합 OOF R²>=0.2이다. 미달이면 주 결론을
  **생산량이 피크를 설명하지 못함**으로 쓰고 분류는 탐색용 감사 자료로만 남긴다.
  개별 폴드 R²<0.2도 별도 표시한다. R²는 전체 설명 모델의 설명력임을 명시한다.
- 유형 비율 날짜 블록 CI와 대표 에피소드 3개를 기록한다. 대표는 각 유형에서
  excess 최대 1개, 부족하면 미선택 에피소드의 excess 내림차순으로 채운다.
- 결과 이름에 _v2를 붙이고 이전 결과를 보존한다.

## 작업 6: 재현·검증

전체 테스트 및 새 지표·이동 시간 제약·share 경계 테스트를 실행한다.
캐시 없는 부분 재실행에서 결정론적 수치 atol=1e-10, rtol=1e-10,
범주·선정·행 수는 완전 일치가 기준이다. 학습 곡선 시간 등 실행시간은 비교 제외.
실패하면 숨기지 않고 원인과 영향 범위를 기록한다. 보호 파일 해시와 테스트 결과
부재를 다시 검사한다. 작업별 기록·커밋을 만들고 force 없이 05_experiments로 push한다.
