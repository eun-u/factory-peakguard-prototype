# FG-R9 사전 고정 (2026-10-07, 후보 결과 확인 전 작성)

배경: FG-R8 최종 테스트(1회)에서 정확 복제 게이트 작동률 1.5%, Chronos-2 단독이 평균 MAE에서 우세.
이번 라운드는 테스트 결과를 본 뒤의 개선이며, 테스트 재평가는 "2차 평가"로만 보고한다.

## 근거한 공개 연구·코드
- GIFT-Eval 상위 파운데이션 모델: Chronos-2(amazon/chronos-2), TimesFM-2.5(google/timesfm-2.5-200m-pytorch),
  TimesFM-3(google/timesfm-3.0-pytorch, 2026-08), TiRex(NX-AI/TiRex). Moirai-2(uni2ts)와 Toto(toto-ts)는
  Windows/Python 3.13에서 의존성(구 scikit-learn 소스 빌드) 설치 실패로 제외.
- 파운데이션 모델 앙상블이 단일 모델보다 낫다는 연구(arXiv 2508.16641, 2507.22053, 2512.16022). 튜닝 없는 평균/중앙값만 사용.

## 선정 규칙
- 평가: 개발 16주(EXPLORE+CONFIRM) score 행 중 **비게이트 행**(테스트 유사 조건)의 13지평 pooled MAE 평균.
- 동점(차이 ≤ 0.05)은 같은 행의 Peak MAE가 낮은 후보.
- 후보: Chronos-2, TimesFM-3, TimesFM-2.5, TiRex 단독; 4개 평균; 4개 중앙값; Chronos+각 모델 2개 평균(3개).
  설치·추론 실패 모델은 해당 후보에서 제외하고 기록.
- 게이트: 오늘 관측 슬롯 수 ≥ k. k는 개발 score 게이트 행 정밀도(|유사일−실측|<0.5) ≥ 0.95가 되는 최소 구간 하한 = 5
  (개발 정밀도: 1~2칸 0.585, 3~4칸 0.887, 5~8칸 0.966, 9칸 이상 ≥0.989).
- 피크 상향 보정(B8, margin 25, CAL 선택)과 CQR 위험 추정은 FG-R8 절차 유지(분위수는 Chronos).
- 최종 잠금은 FG-R8과 같은 28일 보정 구간. 테스트 2차 평가는 1회.

## 추가 후보 (1차 후보 결과 확인 후, 추가 후보 결과 확인 전 작성)

1차 결과: 비게이트 개발 MAE Chronos-2 6.456 < Chronos+TimesFM-3 평균 6.607 < 4개 중앙값 6.975 < TimesFM-3 7.093
< TiRex 8.684 < TimesFM-2.5 9.143. 앙상블은 모두 Chronos 단독보다 나빴다.
추가 후보(같은 선정 규칙): Chronos-2 + 알려진 미래 달력 공변량(시각 sin/cos, 요일, 주말·공휴일);
위 + 과거 전용 공변량 production_known(시간 종료 후 확정 생산량, A8); Chronos-2 문맥 1024.

## 피크 MAE 라운드 (2026-10-08, 후보 결과 확인 전 작성)

개발 진단(비게이트 score 행): 피크는 평일 06~22시에만 발생(휴일·야간 0건), 10~12시 32%, 14~18시 20%, 점심 12~14시 16%.
MOS 보정 후 피크 행 편향 −7~−9(18~22시 −14.4), 원점 정지 상태(램프업) −11.5.

후보(MOS 보정 Chronos 위; 파라미터는 각 주 점수 시작 직전 28일 행에서 선택, 최종 잠금과 동일):
- R10: 고부하(pred > τ−m) 일괄 보정량 (현행, m=25)
- W: 평일 06~22시에만 일괄 보정량
- H: 평일 시간대(06-10, 10-12, 12-14, 14-18, 18-22)별 보정량
- HR: H + 원점 정지 상태(램프업)별 추가 보정량
- P: 평일 06~22시, pred + w·p_exceed·(q90−q50) (w 격자 0~3)
- 하이퍼파라미터: m ∈ {15, 25, 40}
선정: 피크 MAE 최소, 단 평균 MAE ≤ R10(m=25) + 0.05. 이후 최종 잠금 → 테스트 4차 평가 1회(공개).

## 문헌 기반 피크·평균 동시 개선 라운드 (2026-10-08, 후보 결과 확인 전 작성)

근거 문헌: 2단계 피크 판별-회귀(Energies 2017; peak demand forecasting review), PeakFocus(위치 인지 강도 회귀, 2026 preprint),
불균형 회귀 LDS/역밀도 가중(ICML 2021), Balanced MSE(CVPR 2022), 분위수 매핑(기상 후처리).
제조 도메인 특징(원점까지 관측): 근무 시간대 블록(06-10/10-12/12-14/14-18/18-22, 평일), 휴일, 램프업(원점 정지),
오늘 자정 이후 최대값−τ, 같은 슬롯 전일·전주 값−τ, Chronos 초과확률·분위수 폭.

후보(MOS 보정 Chronos 기준, 학습은 각 주 FIT+STOP 비게이트 행, 조정값은 점수 직전 28일 창):
- TS: 2단계 — 로지스틱 피크 판별(도메인 특징) + 고부하 구간 전용 MOS(p>τ−40 행 학습); 확률>θ 행에 전용 MOS+보정량.
  θ와 보정량은 28일 창에서 J=MAE+PeakMAE 최소화.
- LDS: MOS 학습 가중치 = (가우시안 평활 라벨 밀도)^−1/2 정규화 → 현행 보정량 절차.
- QM: 28일 창에서 평일 근무시간 예측의 경험적 분위수 매핑(100분위) → 보정량 없음.
- TS+LDS 결합.
선정: 개발 16주 비게이트 score 행에서 MAE와 Peak MAE가 **모두** 현행 R10(6.411/9.427)보다 낮은 후보 중 Peak 최소.
없으면 현행 유지, 테스트 재평가 없음.

## 문헌 방법 충실 재현 라운드 (2026-10-08, 결과 확인 전 작성)

### TH: 시간 계층 조정 (Athanasopoulos et al., EJOR 2017; Nystrup et al., EJOR 2020)
- 원점 정렬 계층: 집계 k ∈ {1,2,4,8,16}칸(15분·30분·1시간·2시간·4시간), 각 원점에서 다음 16칸을 16+8+4+2+1=31 노드로 구성.
- 기반 예측: 각 k에 대해 원점에 정렬된 k칸 평균 시계열(최근 2048개 집계점)로 Chronos-2 중앙값, 예측 길이 16/k. 원점 이후 값 미사용.
- 조정: OLS, WLS-구조(노드에 포함된 하위 칸 수), WLS-분산(각 주 FIT+STOP 잔차의 수준별 분산), MinT-shrink(같은 잔차로 수축 공분산).
- 비교 1: 조정된 15분 예측 vs Chronos 원예측 (개발 16주 비게이트 행 MAE·Peak).
- 비교 2: 최선 조정안을 기반으로 게이트≥5 + MOS(재학습) + CAL 보정량 → 현행 R10(6.411/9.427)과 비교.

### FT: 피크 인식 미세조정 (PeakFocus·불균형 회귀 재표집 정신)
- Chronos-2 LoRA(lr 1e-5, 300 steps, batch 32, 문맥 2048, 예측 16). 체크포인트 4개: fold 블록 [0-3],[4-7],[8-11],[12-16]의
  첫 점수 원점 − 16칸 이전에 끝나는 창만 학습, 해당 블록 4~5주에만 적용(시간 순서 준수).
- 변형: FT-u(균등), FT-p(미래 16칸에 y>τ 포함 창 ×3 과표집), FT-pn(FT-p + 미래가 정확 복제로 예측 가능한 창 제외 → 테스트 유사 학습).
- 비교: 각 변형 중앙값 vs Chronos 원예측(개발 비게이트 행 MAE·Peak). 개선 시 전체 파이프라인으로 R10과 비교.

### 판정
MAE와 Peak MAE가 모두 비교 대상보다 낮은 후보만 채택. 없으면 현행 유지, 테스트 재평가 없음. 채택 시 최종 잠금 → 테스트 4차 평가(공개).
