# 논문 집필

원본은 `sections/`, 현재 수치는 `generated/results.md`, 읽을 본문은 [manuscript.md](manuscript.md)다. `python -m research build`는 기존 근거만 읽어 본문을 생성한다. 생성 파일을 직접 수정하지 않는다. 관련 문헌·해석은 절 원본에 작성하고 정량 결과는 근거 파일로 연결한다.

| 논문 흐름 | 대회 6장·배점 |
|---|---|
| 배경·데이터·검증 정의 | 1장 데이터 이해 15 |
| 방법·비교 실험·모델 선정 | 2장 모델 개발 40 |
| 실패 조건·강건성·해석 | 3장 오류 분석 15 |
| 운영 적용·가정 시나리오 | 4장 활용 10 |
| 주장별 추가 가치·한계 | 5장 차별성 10 |
| 재현·환경·위협 | 6장 코드/재현 10 |

`report/`의 기존 6장 산출물은 과거 파이프라인 결과로 보존한다. 최신 논문 본문과 동일 버전으로 오인하지 않는다. 지정 양식으로 옮기는 최종 제출 편집은 별도이며 위 매핑을 사용한다. 원자료 사용·블라인드·설문 등 기존 제출 조건은 유지한다.
