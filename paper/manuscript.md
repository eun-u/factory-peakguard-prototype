# 제조 전력피크 예측과 불확실성 기반 선행 경보의 실증 연구

연구 본문 초안 · 개발 결과 · 최종 제출본 아님

수동 집필 원본은 `paper/sections/`, 수치는 `paper/generated/results.md`에 있다. 생성된 본문을 직접 수정하지 않는다.

## 1. 배경과 목적

본 연구는 제조 생산·전력 자료를 이용한 피크 예측과 선행 경보의 유효성을 평가한다. 주 과제는 원점에서 한 시간 뒤에 끝나는 단일 15분 구간의 전력값 예측이다. 정확한 피크 예측과 유용한 경보는 각각 검증할 대상이며, 생산·시간 조건과 입력 지연에 따른 실패 범위를 분석한다.

연구 질문은 RQ1 피크 오차 개선, RQ2 오경보·준비시간을 고려한 경보, RQ3 실패 조건과 강건성, RQ4 근거와 운영 활용이다. 성능 개선을 주 연구 과제로 유지한다. 실측 설비 제어와 실제 전력비 절감은 현재 검증 범위에 포함되지 않는다.

## 2. 선행연구와 연구의 위치

기준선은 지속·계절 패턴·CBL 준용·LightGBM이다. 첨부 LLM-enhanced embodied multi-agent manufacturing system 논문은 시스템 구성, 구성요소 비교, 교란 시나리오, 통합 시연을 연구 흐름으로 연결하는 참고다. 그 논문의 장비 협상·실행 효과나 성능 수치를 본 연구의 성과로 전용하지 않는다.

보강할 문헌 비교는 전력피크 예측, 확률 예측/보정, 시간 제약이 있는 경보 평가다. 현재의 방법적 독창성은 아직 문헌 전체와 대조해 확정하지 않았다. LLM·KG·다중 에이전트는 기본 방법의 필수 구성요소가 아니다. 참고 서지는 `paper/references.bib`에 관리한다.

## 3. 방법

### 3.1 데이터와 예측 대상

원자료 6,168시간 행을 24,672개 15분 관측으로 구성한다. 관측 기간은 2021-01-01 00:15~2021-09-15 00:00이다. 시간 복원 192구간과 이에 의존하는 특징·목표는 제외한다. 전력 단위와 종료 구간 해석은 미확인 가정이다. 완료된 생산량·과거 전력·달력만 원점 기준으로 사용한다.

### 3.2 점예측과 위험 출력

점예측과 분위수·보정 기반 초과확률을 구분한다. 현재 선정은 자동 결과 스냅샷에서 관리한다. 개선 후보는 같은 평가 조건으로 비교하며, 성능 결과를 보고 최종 예측기를 선정한다. 통계적 피크 τ는 학습 95백분위이며 실제 계약 한도와 다르다.

### 3.3 경보와 운영 해석

기존 확률 경보, 확률 또는 q95 경보, 점예측 경보를 비교 기준으로 둔다. 점/확률 결합은 R2-EX02의 미검증 가설이다. 운영 준비시간은 목표 구간 시작 기준으로 정의하고 기존 목표 종료 기준의 수치와 구분한다. 부하 이동 검토에는 미래 시간창 예측과 실제 작업 제약이 추가로 필요하다.

## 4. 실험 설계

개발 데이터의 시간순 학습·조기종료·보정·평가 분리와 같은 평가 행 비교를 유지한다. 주 과제 h4의 피크 MAE, 전체 오차, 점/확률/운영 경보의 사건 지표, 조건부 커버리지를 구분한다. 날짜 블록 쌍별 CI와 정해진 검정군의 다중비교 보정을 사용한다.

기존 P4/P5/P6의 계획·결과·기각을 그대로 보존한다. 후속 실험은 `experiments/registry.json`과 여섯 계획 카드로 관리하며 아직 실행하지 않았다. 분할·후보·예산·판정 기준을 실행 전에 고정한다. 평가 OOF만으로 임계를 튜닝하지 않는다.

마지막 15% 테스트의 과거 1회 열람 사실을 유지한다. 개발 재분할이나 재봉인만으로 미열람 평가가 되는 것은 아니다. 기존 `eval_protocol.md`와 최종 평가의 날짜·사람 승인·해시 조건은 유효하다.

## 5. 결과

이 문서는 기존 결과를 읽어 생성한다. 새 학습·정책 실험·최종 평가는 실행하지 않는다. 오차는 원자료 단위이며 단위 미확인 상태를 유지한다.

| 비교 | 기준 | 후보 | 개선량과 범위 |
| --- | --- | --- | --- |
| h4 피크 MAE / P4 | 14.443 | 12.579 | 1.864, CI [0.877, 2.779], Holm p=0.028 |
| 점예측 경보 F1 / P4 | 0.589 | 0.573 | 확률 경보 지표와 구분 |
| 점예측 경보 FP 위치 / P4 | 593 | 635 | 15분 위치 수, 알림 사건 수 아님 |
| h4 Chronos 피크 MAE / P5 | 12.579 | 10.804 | CI [-0.442, 3.992], 미채택 (peak_gain_not_significant_after_holm;episode_f1_drop;fp_increase) |

h4 실제 사건 148개: 적중 88, 늦은 적중 6, 규칙 기반 판단 미탐 51, 예측 미탐 3. 미탐 중 52개에 점예측 경보가 존재한다. 결합 정책의 추가 적중·준비시간·오경보 개선은 아직 검증하지 않았다.

P6 갱신 전략은 탐색 결과다. 아래 값은 주별 상위 q95 커버리지의 평균과 피크 MAE 집계이며, 전체 표본의 단일 커버리지와 구분한다.

## 6. 논의와 현장 활용

현재 결과는 피크 예측 개선과 경보 개선을 분리해야 함을 보여 준다. 미탐 사건에서 관측된 다른 신호는 새 정책의 동기이며 개선량이 아니다. 분할·계절 변화·입력 지연에 따른 결과를 함께 해석한다.

근거 기반 의사결정 지원은 사건의 관측·예측·규칙·가정을 연결하는 방향으로 개발한다. 사후 관측 생산량에 기반한 이동 시나리오를 실제 실행 가능한 최적 스케줄이나 실현 절감으로 표현하지 않는다. 정형 템플릿보다 복잡한 설명 기법은 동일 정보량에서 추가 가치를 검증한다.

## 7. 타당성 위협

- 내적 타당성: 개발 결과 반복 확인, 사후 후보 승격, 선택 편향, 과거 테스트 열람.
- 구성 타당성: 전력 단위·15분 경계 가정, 통계적 피크와 운영/계약 한도의 차이, 위치·사건·알림의 다른 분모.
- 외적 타당성: 제한된 기간과 공장, 겨울 전체 구간 부재, 설비·제품·교대·작업 제약 미관측.
- 효과 해석: 변수 중요도와 사례 유사성은 인과 증거가 아니며 사후 시뮬레이션은 현장 효과를 입증하지 않는다.
- 재현 범위: 현재 연구 관리 명령은 추적된 작은 결과 파일만 읽는다. 전체 학습 재현에는 별도 원자료·모델·잠금 환경이 필요하다.

## 8. 현재 결론과 검증할 기여

기존 개발 비교에서는 h4 피크 점예측 개선을 확인했다. 경보 부담, 준비시간, 기간별 안정성과 실제 운영 효과는 각각의 증거로 평가해야 한다. 후속 실험의 결론은 아직 작성하지 않는다.

검증할 기여는 (1) 강한 기준선 대비 피크 성능과 유효 범위, (2) 점예측·불확실성·준비시간을 연결한 경보의 추가 효과, (3) 제조 맥락·지연·기간 변화에서의 실패 조건이다. 구현한 기능의 수를 기여의 근거로 사용하지 않는다.
