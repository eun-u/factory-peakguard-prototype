# 연구 질문별 실험 관리

[등록부](registry.json)가 ID·가설·비교·평가·판정·다음 행동을 연결한다. [계획 카드](plans/)는 실행 전 조건을 상세화한다. H-P4/H-P5/H-P6/H-OPS는 완료된 역사적 실험이고 R2-EX01~06은 미실행 후속 설계다. 신규 카드가 존재한다는 이유만으로 사전등록 완료나 실험 완료가 되지 않는다.

계산 구현은 현재 `src/`, `research_p4/`, `scripts/`에 있다. 기존 import·실행 경로와 원 결과의 해시를 유지한다. 등록부는 기존 코드 위치를 연결하는 연구 진입점이다. 코드를 이동할 때는 호환성·과학적 지문·재현 검증을 함께 변경해야 한다.

연구 단위: 질문 → 관찰/선행 근거 → 가설 → 방법 → 비교 실험 → 결과/CI → 해석/위협 → 주장 → 논문 위치.
