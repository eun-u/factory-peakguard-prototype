# R2-EX03 — 구성요소 제거 실험

상태: planned · 결과를 확인한 뒤 수립한 후속 설계 · 아직 실행 전 등록 완료가 아님

| 항목 | 설계 |
|---|---|
| 연구 질문 | RQ1, RQ2 |
| 연결 주장 | C01, C02 |
| 가설 | 맥락·보정·결합 요소는 각각 추가 가치를 갖는다. |
| 비교 | 생산/달력 맥락 제외, 보정 A/B, 결합 구성요소 제거 |
| 평가 | 동일 행의 오차·보정·경보 변화와 CI |
| 판정 원칙 | 한 요소씩 비교하며 부정적 효과도 기록. 기존 유효 비교는 재사용. |
| 다음 행동 | 기존 제거 실험을 대응시키고 빠진 비교만 지정한다. |

## 실행 전 확정할 항목

1. 대상 데이터/분할/원점과 보정·평가 경계, 가용 시각.
2. 후보의 정확한 설정, 탐색 횟수·계산 예산, 변경한 요소와 고정한 요소.
3. 주 지표·보조 지표·분모, 실용 허용폭 또는 미확인 상태, CI·검정군.
4. 결과 경로, 코드 커밋, 실행 환경, 실패·기각 시 기록 방식.

평가 규칙의 과거 변경은 소급 은폐하지 않는다. 신규 계획 확정은 `DECISIONS.md`에 기록하고 최종 테스트의 기존 날짜·사람 승인·해시 조건을 유지한다.

## 결과 기록

미실행. 결과/CI/채택·기각/한계/후속 질문을 실행 후 작성한다. 좋은 결과만 남기지 않는다.
